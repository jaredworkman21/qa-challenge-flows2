# Pathways

A small lesson builder. Authors build a lesson out of screens and preview it the way a learner would see it.

## Running it

```bash
npm install
npm run dev
```

Open http://localhost:5173.

Lessons are saved in your browser's local storage, so there's no backend to run. To start over, clear site data for localhost.

## Scripts

- `npm run dev` starts the dev server
- `npm run build` typechecks and builds
- `npm test` runs the unit tests
